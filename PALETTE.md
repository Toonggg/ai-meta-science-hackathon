# Colour palette

The review desk and the jury deck use the same palette, taken from the Nerva Care OS deck:
deep navy, electric blue, and a neon lime accent on a near-white page. The scheme has no
official name; describe it as "navy and electric blue with a neon lime accent". Defined in
`ui/styles.css` as CSS variables.

| Variable | Hex | Role |
|---|---|---|
| navy | #0b1020 | dark panels, hero cards |
| navy-2 | #151b2e | raised surfaces on navy |
| navy-3 | #1f2638 | borders and table heads on navy |
| ink | #0e1424 | body text |
| blue | #3d5afe | primary action, links |
| blue-2 | #8ea2ff | secondary blue, arrows |
| blue-tint | #e6eaff | light blue fills, chips |
| lime | #c8ff3d | accent, highlights, Ready |
| lime-tint | #f0ffd0 | light lime fills |
| bg | #f4f5f8 | page background |
| card | #ffffff | cards |
| border | #e3e6ee | card borders |
| muted | #667085 | secondary text |

Status colours used by the bands:

| Band | Fill | Text |
|---|---|---|
| Ready (green) | #f0ffd0 | #3a5200 |
| Check (amber) | #fff3d1 | #7a4b00 |
| Decide (red) | #ffe5e2 | #9b1c1c |

Type: Inter for text, Instrument Serif for display headings. Corner radius 22 px.
