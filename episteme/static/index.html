    Model provider
    
    
    Episteme works offline with heuristics. Connect any model for deeper analysis. Settings and keys stay on this machine in .episteme/config.json.
    
    
    
    
    
    
    
    
    
    
    
      
    Search sources
    
      
    Free sources are queried together and merged. If one is down or rate-limited it is paused and the others cover for it. Web engines need your own key and are tried in order until one answers. All sources are re-checked every 10 minutes.
